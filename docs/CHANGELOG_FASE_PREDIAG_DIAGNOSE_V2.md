# Changelog — Diagnóstico AURA v2

- Diagnose ahora explica la arquitectura Pre-Diagnóstico → Diagnóstico AURA → Prescripción futura.
- Diagnóstico completo alineado al recorrido Consulta → Respuesta → Seguimiento → Cita → Venta.
- Preguntas y evidencia generalizadas para negocios de servicios, no solo pacientes/clínicas.
- Capacidad y demanda incorporadas explícitamente en la entrevista.
- Venta y medición se tratan como cierre del recorrido.
- Automatización e IA se evalúan después del proceso, no como conclusión automática.
- Informe AURA deja de mostrar una implementación con precio fijo.
- Prescripción comercial se presenta como fase separada y todavía no activada.
- Labels de interfaz actualizados a “Diagnósticos AURA”.
- No se modificaron tablas, columnas, RLS ni datos por esta actualización.
